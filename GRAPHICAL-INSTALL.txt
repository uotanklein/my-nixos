NixOS GRAPHICAL ISO → HYPRLAND + CAELESTIA
GitHub-редакция, 21.10.2026

ЦЕЛЬ

Graphical ISO используется как временная среда с браузером, сетью и терминалом.
На SSD устанавливается наша отдельная конфигурация: Hyprland + Caelestia,
экран входа greetd/tuigreet, драйверы и необходимые приложения.
В конфигурации явно отключены окружения GNOME/KDE Plasma и вход GDM/SDDM.

Основной сценарий ниже — ручная установка из терминала Graphical ISO.
Графический установщик Calamares запускать не нужно. Если его окно открылось
автоматически, закрой его. Не запускай два установщика одновременно.

0. ПЕРЕД ПЕРЕЗАГРУЗКОЙ CACHYOS

Сохрани нужные личные файлы и VPN-профиль ВНЕ стираемого SSD.
В публичном репозитории VPN-ключей нет. Отдельный личный архив, подготовленный
ранее, содержит private/AmneziaVPN.conf: не загружай его в GitHub.
Документы, браузерный профиль, игры, Wi-Fi-пароли и профиль приложения этой
переписки в комплект не входят — сохрани их отдельно.

Скачай Graphical ISO для 64-bit Intel/AMD (x86_64), NixOS 26.05 или новее:
https://nixos.org/download/#nixos-iso
Подготовь загрузочную флешку и загрузи её через пункт UEFI USB.
Конфигурация рассчитана на UEFI/systemd-boot без Secure Boot.

CachyOS установлена на Samsung SSD 870 EVO 1TB.
Серийные номера не публикуются. В live-сессии найди этот SSD по модели,
объёму и серийному номеру; затем выбери соответствующее имя /dev/disk/by-id/.
Имена /dev/sda и /dev/sdb могут измениться при загрузке ISO.
Остальные HDD/NVMe/USB не форматируй.

1. РАБОЧИЙ СТОЛ ФЛЕШКИ

В загрузочном меню выбери удобную графическую сессию (GNOME или Plasma).
Она работает с флешки и сама по себе не устанавливается на SSD.
Подключи Wi-Fi через меню сети или подключи Ethernet.
Открой сохранённую GRAPHICAL-INSTALL.txt в текстовом редакторе или браузере
и терминал live-сессии рядом.

В терминале проверь UEFI и сеть:
  test -d /sys/firmware/efi && echo UEFI
  curl -I https://cache.nixos.org

Если UEFI не выведено, перезагрузи флешку в режиме UEFI.
Выбор рабочей среды флешки на финальные Hyprland/Caelestia не влияет.

2. СКЛОНИРОВАТЬ РЕПОЗИТОРИЙ

В терминале Graphical ISO:
  git clone https://github.com/uotanklein/my-nixos.git
  cd my-nixos

Если git отсутствует:
  nix-shell -p git
и выполни команды клонирования внутри этой оболочки.

Клонируй в домашнюю папку live-пользователя, не на стираемый SSD.
Для копирования в терминале live-сессии обычно используются
Ctrl+Shift+C / Ctrl+Shift+V. Настройки Kitty применятся после установки.

Необязательно: для переноса сохранённых серверов AmneziaVPN создай private/,
скопируй туда AmneziaVPN.conf из личного архива/внешнего носителя и выставь:
  chmod 700 private
  chmod 600 private/AmneziaVPN.conf
Папка private/ исключена из Git. Без профиля система установится нормально;
сервер VPN нужно будет импортировать в приложении вручную.

Вариант без Git: Code → Download ZIP на GitHub, распаковать архив и открыть
терминал в папке my-nixos-main. Дальнейшие команды те же.

3. ПОДГОТОВИТЬ SSD

Посмотри все диски:
  lsblk -d -o NAME,SIZE,MODEL,SERIAL
  ls -l /dev/disk/by-id/

Для ПОЛНОГО УДАЛЕНИЯ старой CachyOS на указанном Samsung SSD выполни:
  sudo bash prepare-disk.sh /dev/disk/by-id/ИМЯ-ТВОЕГО-SAMSUNG-SSD

Помощник покажет диск, предупредит об удалении ВСЕХ его разделов и потребует
ввести ERASE-СЕРИЙНЫЙ_НОМЕР. Это необратимая операция для выбранного диска.
Она не запускается автоматически установочным скриптом.

Если файловый менеджер live-сессии уже смонтировал разделы этого SSD,
помощник остановится. Отмонтируй именно их через приложение «Диски» или
файловый менеджер, проверь lsblk и повтори. Носитель с архивом не трогай.

После подтверждения будут созданы и смонтированы:
- EFI FAT32 4 ГиБ в /mnt/boot;
- Btrfs, подтом @ в /mnt;
- Btrfs, подтом @home в /mnt/home;
- сжатие zstd, noatime; swap будет в zram.

Если не хватает утилит подготовки, открой оболочку с ними:
  sudo nix-shell -p parted dosfstools btrfs-progs
и в ней повтори команду помощника БЕЗ повторного sudo.
После завершения выйди из этой оболочки командой exit.

Если разделы уже готовы или ты хочешь другую разметку, помощник пропусти.
Нужно смонтировать корень Btrfs/ext4 в /mnt и EFI FAT32 в /mnt/boot,
а отдельный /home — в /mnt/home. Скрипт установки проверит эти точки.

Проверка:
  findmnt /mnt
  findmnt /mnt/boot
  findmnt /mnt/home

4. УСТАНОВИТЬ СРАЗУ НУЖНУЮ СИСТЕМУ

Из папки комплекта выполни:
  sudo bash install-from-iso.sh

Имя пользователя по умолчанию — uotanklein. Для другого имени:
  sudo bash install-from-iso.sh --user myname

Сценарий создаёт аппаратную конфигурацию по реальным разделам,
настраивает UEFI/systemd-boot, пользователя/sudo, сеть, NVIDIA RTX 5070,
Bluetooth/звук, greetd/tuigreet, Hyprland и Caelestia.
Он сохраняет system.stateVersion, сгенерированную установочным ISO.

Во время установки будет предложено задать пароль root, затем отдельно
пароль обычного пользователя. Эти пароли не записываются в файлы архива.
После сборки восстанавливаются настройки рабочего стола. Сохранённые серверы
AmneziaVPN переносятся только если ты отдельно добавил private/AmneziaVPN.conf.

Графический рабочий стол live ISO не копируется в установленную систему.
GNOME/Plasma и GDM/SDDM принудительно отключены в desktop.nix.
Dolphin, текстовый редактор и другие отдельные приложения сохраняются;
полные окружения GNOME/KDE при этом не включаются.

Первая сборка может долго скачивать/собирать пакеты. Можно оставить терминал
открытым, а рядом читать инструкцию в браузере. Дождись «Установка завершена».
При ошибке сохрани текст и не перезагружайся до её разбора.
После исправления причины можно повторить install-from-iso.sh на тех же
разделах; prepare-disk.sh повторять НЕ НУЖНО.

Настройки Wi-Fi live-сессии автоматически не считаются сохранёнными
для установленной системы. После первой загрузки при необходимости запусти nmtui.

5. ПЕРЕЗАГРУЗКА И ПЕРВЫЙ ВХОД

После успешного завершения:
  sync
  sudo reboot

Выбери новый SSD/запись NixOS в UEFI, а не снова USB.
Появится текстовый экран входа tuigreet. Введи имя пользователя и пароль —
запустится Hyprland + Caelestia. Переключатель сессий GNOME/KDE здесь не нужен.

Сохранены:
- Samsung слева, MSI G274QPF основной в центре, MSI MP275 E2 справа;
- Super+Space и Alt+Shift для US/RU, исправление Caps Lock;
- одиночный Super открывает меню, Super+Enter — Kitty;
- Ctrl+C/Ctrl+V в Kitty, обои, оформление и остальные сочетания;
- AmneziaVPN и системная служба; серверы/автоподключение — при добавлении профиля.

Проводной DHCP должен получить сеть автоматически. Для Wi-Fi открой Kitty
по Super+Enter и выполни nmtui. После подключения проверь AmneziaVPN.
Bluetooth-наушники сопряги заново и выбери EDIFIER выходом звука.

Проверки:
  nvidia-smi
  hyprctl monitors
  hyprctl configerrors
  systemctl --failed
  systemctl --user --failed
  wpctl status
  systemctl status AmneziaVPN

Если названия портов мониторов изменились, сверь hyprctl monitors с
hardware-summary.json и поправь ~/.config/hypr/config/monitors.lua и
variables.lua. Затем выполни hyprctl reload.

6. ЕСЛИ УЖЕ УСТАНОВИЛ ЧЕРЕЗ ГРАФИЧЕСКИЙ УСТАНОВЩИК

Если вместо основного сценария ты уже воспользовался Calamares, можно применить
комплект после установки. При выборе окружения удобнее указать «без рабочего
стола»; если GNOME/KDE уже выбраны, наш модуль их отключит.

Загрузи установленную NixOS. Склонируй репозиторий. Перейди на Ctrl+Alt+F2 и войди
своим пользователем с sudo или root. На tty1 сценарий не запускается:
greetd займёт tty1 и мог бы прервать текущий вход.

От обычного пользователя:
  bash install.sh
От root или с указанием пользователя:
  sudo bash setup-installed.sh --user uotanklein
(Если ты уже root, sudo не нужен.)

Параметры дисков, загрузчик и stateVersion этой установки сохранятся,
пользователь и нужные компоненты настроятся, настройки перенесутся.
После успешного завершения перезагрузи ПК. Старые поколения NixOS могут
продолжать хранить прежние пакеты на диске; активное новое поколение использует
Hyprland/Caelestia. Не удаляй поколения до проверки новой системы.

7. ВОССТАНОВЛЕНИЕ

Если графика не запускается, Ctrl+Alt+F2 открывает консоль. Входи обычным
пользователем с sudo или root с паролем, заданным при установке.
При первой установке предыдущего поколения NixOS может ещё не быть;
сохрани флешку и архив до проверки графики, сети, звука и VPN.

Из Graphical ISO можно смонтировать уже установленные разделы и открыть систему:
  sudo mount -o subvol=@ /dev/РАЗДЕЛ_BTRFS /mnt
  sudo mkdir -p /mnt/home /mnt/boot
  sudo mount -o subvol=@home /dev/РАЗДЕЛ_BTRFS /mnt/home
  sudo mount /dev/РАЗДЕЛ_EFI /mnt/boot
  sudo nixos-enter --root /mnt

Здесь нужно подставить реальные разделы. Это монтирование без форматирования.
Внутри установленной системы после исправления конфигурации:
  nixos-rebuild boot --flake /etc/nixos#desktop

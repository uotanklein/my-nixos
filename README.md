# NixOS: Hyprland + Caelestia

Личная конфигурация для перехода с CachyOS на NixOS из **Graphical ISO**.
На SSD устанавливаются Hyprland + Caelestia и экран входа greetd/tuigreet.
GNOME, KDE Plasma, GDM и SDDM явно отключены.

## Начало установки

Загрузись с Graphical ISO в режиме UEFI, подключи интернет и открой терминал.
Графический установщик Calamares запускать не нужно.

```bash
git clone https://github.com/uotanklein/my-nixos.git
cd my-nixos
```

Если `git` отсутствует, сначала выполни `nix-shell -p git`.
Далее следуй [пошаговой инструкции](GRAPHICAL-INSTALL.txt): проверь выбранный
SSD, подготовь разделы и затем запусти `sudo bash install-from-iso.sh`.

**`prepare-disk.sh` полностью удаляет выбранный диск.** Это отдельный ручной
шаг с проверкой модели/серийного номера и подтверждением; установщик сам его
не вызывает. Не запускай его на диске, с которого работаешь или хранишь бэкап.

## Разметка

| Область | Размер | Формат / точка монтирования |
|---|---:|---|
| EFI | 4 ГиБ | FAT32, `/boot` |
| Остальное | Всё свободное место | Btrfs: `@` → `/`, `@home` → `/home` |

Система и домашний каталог делят свободное место Btrfs, включено сжатие zstd.
Swap — zram. Шифрование и гибернация не настроены. Параметры реальных разделов
генерируются на месте установки. Пароли задаются интерактивно.

## Сохранённые настройки

- Ryzen 7 7700, 32 ГиБ ОЗУ, NVIDIA RTX 5070 с открытым модулем NVIDIA.
- Samsung S24D332 слева, MSI G274QPF основной в центре, MSI MP275 E2 справа.
- US/RU по **Super+Space** и **Alt+Shift**, исправление задержки Caps Lock.
- Одиночный Super открывает меню; Super+Enter запускает Kitty.
- Ctrl+C / Ctrl+V в Kitty, оформление Caelestia, обои, прочие горячие клавиши.
- Bluetooth, PipeWire, AmneziaVPN, Firefox и обычные приложения.
- Русская локаль, часовой пояс Europe/Moscow.

После установки наушники нужно сопрячь заново и выбрать выход звука.
Wi-Fi при необходимости настраивается через `nmtui`.
Данные мониторов: [hardware-summary.json](hardware-summary.json).
Настройки портов корректируются в `~/.config/hypr/config/monitors.lua` и `variables.lua`.

## VPN-профиль хранится отдельно

**В репозитории нет VPN-ключей, серверов, паролей, серийных номеров дисков
или прежних адресов Bluetooth-устройств.**

До стирания CachyOS сохрани VPN-профиль и личные файлы на другом носителе.
В ранее подготовленном личном архиве профиль находится в `private/AmneziaVPN.conf`.
Чтобы перенести его автоматически, перед установкой скопируй его в такую же
папку внутри клона и установи права:

```bash
chmod 700 private
chmod 600 private/AmneziaVPN.conf
```

`private/` исключена из Git. Не используй `git add -f` для этой папки.
Скрипт копирует профиль только в домашний каталог, вне `/etc/nixos` и Nix store.
Без него система также устанавливается, но сервер нужно импортировать в
AmneziaVPN вручную; восстановление прежнего автоподключения требует профиля.

## Уже установленная NixOS

Перейди на Ctrl+Alt+F2, войди своим пользователем и из папки клона выполни:

```bash
bash install.sh
```

Этот сценарий сохраняет текущую разметку, загрузчик и `system.stateVersion`.
Подробности — в [GRAPHICAL-INSTALL.txt](GRAPHICAL-INSTALL.txt).

После установки системная конфигурация находится в `/etc/nixos`.
Применение её изменений:

```bash
sudo nixos-rebuild switch --flake /etc/nixos#desktop
```

Источники закреплены в `nixos/flake.nix` и `nixos/flake.lock` на 21.10.2026.
Системные Nix-модули совпадают с проверенным личным комплектом.

GitHub-копия не включает приватные данные; восстановление допускает их отсутствие.
Полная сборка, установка и загрузка на реальном ПК ещё не проверены.
